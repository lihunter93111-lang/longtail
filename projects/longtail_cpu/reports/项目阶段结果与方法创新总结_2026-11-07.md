## 1. 当前结论

当前应保留的内部验证候选是：**自然数据训练的 DFMS-IQ 主分支 + 组合采样 FMB 专家 + 非线性局部决策头 + SawFM/MFT 分段统计残差头 + ISRJ 分段统计残差头**，沿用已冻结的逐类阈值。

已经获得较明确证据的新增收益有两项：

1. **SawFM/MFT 的 1/2/4 段统计读出**：同一独立报告池上，Exact 从 74.683% 提高到 75.724%，增加 **1.042 个百分点**；相对同预算、同可训练参数量的全局读出控制仍增加 **0.908 个百分点**。收益主要集中在 MFT。
2. **ISRJ 的独立分段统计头**：另一份独立报告池上，Exact 从 75.045% 提高到 76.721%，增加 **1.677 个百分点**；ISRJ 弱召回提高 **8.528 个百分点**，弱 AP 提高 **8.309 个百分点**，误报率下降 **1.442 个百分点**。

这两轮均使用五种子，且同时超过冻结参考和相同训练预算的全局特征控制，通过各自预先设定的内部验收门槛。它们支持的解释是：**冻结主干中已有的局部时序信息没有被原全局读出充分利用，改进读取方式能够提高识别效果。** 它们不证明网络已经学会对应干扰的物理机理。

最新一轮 SawFM 可训练投影未通过两种子筛选；参数量相近的宽头在正式报告上只增加 0.141 个百分点，未达到 0.5 个百分点的采用门槛，因此本轮不替换当前模型。

## 2. 项目任务与评价口径

项目研究的是标签长尾与混合分量功率不均衡共同作用下的复合干扰识别。模型输入单条接收复数 I/Q，输出六个干扰标签是否存在。

| 项目 | 当前设置 |
| --- | --- |
| 标签顺序 | FMB、AMA、SawFM、SinFM、MFT、ISRJ |
| 输入 | I/Q 两通道，长度 3000；采样率 10 MHz，对应 300 微秒观测 |
| 输出 | 六类存在概率；属于多标签任务 |
| 合法组合 | 六类的 63 种非空组合，均为合法标签组合 |
| 当前 v3 主分布 | 各存在分量独立采样 10–30 dB JNR |
| 弱分量定义 | 比同一混合信号中的最强分量至少低 10 dB |
| 训练身份 | 当前固定主分支来自自然 32k 训练池；更早的长尾基线使用 8k 池 |
| 尾类 | 按训练标签计数确定，当前为 AMA、SinFM |

这里的“弱”是**相对混合分量的功率差**，不是简单等同于低绝对 JNR。10–30 dB 的主分布不覆盖超过 20 dB 的分量功率差。

主要指标的含义：

- **Exact**：一条样本的六个标签全部判断正确才计为正确，是本文“整体识别正确率”的口径。
- **Macro-F1 / Macro-AUPR**：先计算逐标签指标，再对六类平均；不能替代整组正确率。
- **弱 AP**：每类只比较“真实弱正例 + 该类缺席的负例”，排除强正例，更直接反映弱分量排序能力。
- **FPR**：在该类缺席的样本中预测为存在的比例；提高弱召回时必须同时检查。
- **pp / 个百分点**：例如 75%→76% 为 +1 pp，不是相对提高 1%。

主报告通常对 63 个组合等量取样。最新 8064 条主报告即每组合 128 条，衡量的是该组合分布下的效果，不能自动代表实际业务中的组合频率。

早期 Query2Label 路线使用过另一套固定功率后衰减的 joint 数据。其约 45%–51% 的 Exact 与后续 v3 的约 63%–77% **不属于同一实验条件，不能构成分数演进曲线**。

## 3. 当前实际算法框架

### 3.1 主干与分段特征

主分支采用 DFMS-IQ，原基础网络参数量为 257,511。冻结主干可提供两种读取位置：

- 投影后的全局向量 `g ∈ R^128`；
- 全局池化前的时序特征 `F ∈ R^(128×375)`。

新增分段统计对 `F` 分别划分为 1、2、4 个时间段，在每段内计算每个通道的均值和标准差，再拼接：

```text
分段数合计：1 + 2 + 4 = 7
每段维度：128 通道 × 2 种统计 = 256
总维度：7 × 256 = 1792
处理：训练集标准化 → 训练集拟合 PCA128 → 小型 GELU 残差头
```

标准化和 PCA 只使用自然训练身份拟合，不使用 calibration、check、report 或配对报告身份。分段头读取的是原模型已经提取的特征，不额外要求干净分量、真实功率或配对差分作为推理输入。

### 3.2 按标签组合决策分支

当前不是把所有历史头简单相加。按实现，主要关系如下：

```text
单条接收 I/Q
  ├─ 自然训练的 DFMS-IQ 主分支 B
  │    ├─ 全局 128 维向量
  │    │    ├─ 线性分类头：提供基础 logits
  │    │    ├─ 原全局非线性局部头：保留其 ISRJ 残差
  │    │    └─ 6.25% 分层配对头：提供 SawFM/MFT 残差
  │    └─ 池化前 128×375 时序特征
  │         └─ 1/2/4 段统计 → 标准化/PCA128
  │              ├─ SawFM/MFT 分段残差头：128→32→2
  │              └─ ISRJ 分段残差头：128→32→1
  └─ 组合采样 DFMS-IQ 专家：仅使用 FMB 输出
       ↓
     六类 logits → sigmoid → 原冻结逐标签阈值
```

更精确地，记 `l_k(g)` 为线性头输出、`r_pair` 为两标签配对头、`r_global` 为原局部头、`r_seg` 为分段头，则：

```text
FMB：   组合采样专家的 FMB logit
AMA：   l_AMA(g)
SinFM： l_SinFM(g)
SawFM： l_SawFM(g) + r_pair,SawFM(g) + r_seg,SawFM(F)
MFT：   l_MFT(g)   + r_pair,MFT(g)   + r_seg,MFT(F)
ISRJ：  l_ISRJ(g)  + r_global,ISRJ(g) + r_seg,ISRJ(F)
```

配对头**替换**了原局部头的 SawFM/MFT 残差，不是把两套相同目标残差重复叠加。新增 ISRJ 头只改变 ISRJ，新增双标签分段头只改变 SawFM/MFT。

该结构仍需自然主分支和 FMB 专家两次主干推理。新增分段头可以共用主分支时序特征，但全模型还包含 PCA、历史头和冻结权重，不能用“4194/4161 个新增可训练参数”冒充完整模型大小。目前没有给出当前完整结构的独立端到端吞吐、延迟和部署内存基准。

当前正式采用的模型清单为：[ISRJ 分段候选五种子清单](../delivery/receipts/isrj_segment_cpu_20261105/selected_models.json)。最新 SawFM 轮次的清单虽然记录了 check 预选 `pca_wide`，但 `formal_report_acceptance=false`，不能据此替换已验收候选。

## 4. 长尾基线：收益来自采样、损失还是阈值？

第一轮同池五种子对照包含 5 个训练方法；逐标签 F1 calibration 是每个模型的一种决策条件，不是第 6 个独立网络。各组均为 DFMS-IQ、24 轮、每轮 250 步、batch32、相同训练预算。

| 方法 | 固定 0.5 Exact | F1 校准 Exact | F1 校准 Macro-F1 | Macro-AUPR |
| --- | ---: | ---: | ---: | ---: |
| ordinary BCE | 57.698% | 63.373% | 92.305% | 97.759% |
| label-aware sampler | 56.776% | 62.168% | 92.108% | 97.603% |
| combo-aware sampler | **65.258%** | 63.800% | 92.543% | 97.918% |
| weighted BCE | 57.277% | 56.627% | 90.656% | 96.873% |
| Logit Adjustment | 63.785% | 63.497% | 92.309% | 97.771% |

可以作出的归因：

- **阈值收益较大**：ordinary BCE 的逐类 F1 校准带来 +5.675 pp Exact，主要缓解 FMB 误报。
- **组合采样改善训练曝光和先验匹配**：均匀采样 63 个组合后，各类期望曝光约 50.79%；label-aware 因标签共现仍使 FMB 曝光约 84.14%、AMA 约 38.69%，没有真正平衡六类曝光。
- **组合采样并非所有标签都更好**：其固定 0.5 Exact 最高，但相对 BCE+F1 的尾类 F1 下降 1.643 pp；双方都做 F1 校准后，Exact 差距缩小到 +0.427 pp，描述性区间跨零。
- **损失替换没有确证额外优势**：LA 在同样校准后基本持平；当前 weighted BCE 导致 FMB 排序退化。
- **逐标签 F1 与整组 Exact 目标不一致**：组合采样经过 F1 校准后，Exact 反而下降，说明不能默认“加校准一定更好”。

可信度边界：这轮发现 `seed+epoch` 导致不同模型种子在偏移轮复用采样流；模型初始化仍不同，但不应把该轮区间解释为独立采样流的严格显著性证据。后续已改为对 `(seed, epoch, stream)` 分域派生随机种子。

修正采样流后，新报告池上的五种子验证为：

| 方案 | Exact | Macro-F1 | 尾类 F1 |
| --- | ---: | ---: | ---: |
| 自然 BCE + F1 | 62.996% | 92.230% | 97.053% |
| 纯组合采样 + 0.5 | 65.218% | 92.575% | 95.929% |
| 50/50 混合采样 + 0.5 | 66.190% | 92.855% | 96.288% |
| 50/50 混合采样 + 受约束 Exact 校准 | 66.215% | 93.072% | 96.707% |
| FMB 组合专家 + 其余标签自然 BCE 的预定义融合 | **68.423%** | **93.577%** | **97.053%** |

融合相对同池自然 BCE+F1 提高 **5.427 pp**，条件配对 95% 区间 `[+4.875,+5.979] pp`，五种子均提高。其启示是不同标签需要不同训练分布；代价是两模型推理。该融合属于项目方法组合，不能视为新型通用集成算法的首创。

证据：[首轮长尾归因](longtail_v3_controls_20261102/analysis.html)、[修正采样流后的对照](combo_optimization_cpu_20261103/analysis.html)。

## 5. 新增方法一：冻结主干的非线性局部决策头

新增设计是把表征学习和决策边界拆开：冻结原主干，仅在全局 128 维特征上训练小型非线性残差，优先作用于 SawFM/MFT/ISRJ，同时保留其他类及 FMB 专家。

在首次顺序验证中：

| 阶段 | 同池参考 Exact | 候选 Exact | 增益 | 验收 |
| --- | ---: | ---: | ---: | --- |
| 固定 logits，仅更改决策 | 71.503% | 71.855% | +0.352 pp | 未通过 |
| 冻结特征，重训线性头 | 71.558% | 71.667% | +0.109 pp | 未通过 |
| one-bit 配对 BCE 非线性局部头 | 72.133% | 73.462% | **+1.329 pp** | 通过 |

三个阶段使用不同报告池，不能把其增益相加。第三阶段中，自然数据非线性头已经提供 +0.957 pp；加入配对 BCE 的额外收益为 +0.372 pp，区间 `[-0.047,+0.791] pp`，不能把全部提升归因于配对。

随后在新训练身份和新报告池上，普通非线性局部头相对自身线性基线：

- Exact：73.433%→74.782%，**+1.349 pp**；
- 条件配对 95% 区间：`[+0.910,+1.789] pp`，五种子均提高；
- 相对前一轮固定候选仅 +0.486 pp，区间跨零，未证明稳定超过旧候选。

因此，**小型非线性决策头相对线性头有效**这一点得到复现；“新候选全面超过旧候选”和“配对本身是主要收益来源”则没有得到相同强度的证据。

证据：[顺序验证](staged_boundary_cpu_20261104/analysis.html)、[独立复现复核](replication_temporal_cpu_20261104/review.html)。

## 6. 新增方法二：按功率差分层的小比例 one-bit 配对

### 6.1 设计与数据合理性

针对 SawFM/MFT，构造共享背景和接收噪声、只增删一个目标分量的正负配对。训练按 6–10、10–15、15–20 dB 功率差分层，使配对集中覆盖弱分量边界。自然身份与配对身份、训练与配对边留出分别审计；模型每次仍只输入单条 I/Q。

比较 0%、6.25%、12.5% 配对视图，保持初始化、优化器和 6000 步训练预算相同。6.25% 对应每 batch32 为 30 条自然视图 + 1 对配对视图。

### 6.2 效果与结论

| 方法 | Exact | SawFM 弱召回 | MFT 弱召回 | 两目标平均 FPR |
| --- | ---: | ---: | ---: | ---: |
| 固定参考 | 74.506% | 47.319% | 68.751% | 3.707% |
| 0% 自然继续训练 | 74.608% | 47.653% | 69.465% | 3.674% |
| 6.25% 分层配对 | 74.688% | 49.499% | 70.976% | 4.083% |
| 12.5% 分层配对 | 74.665% | 50.812% | 71.626% | 4.357% |

6.25% 相对固定参考的 Exact 仅 +0.181 pp，区间 `[-0.035,+0.397] pp`，**整体正确率验收未通过**。两目标平均弱召回 +2.202 pp，区间 `[+1.474,+2.931] pp`，通过允许小幅误报增加的辅助权衡门槛。

相对同预算的 0% 控制，其额外 Exact 只有 +0.079 pp，区间跨零；平均弱召回 +1.679 pp、弱 AP +0.177 pp，但 SawFM FPR 增加 0.549 pp，未通过更严格的辅助门槛。12.5% 进一步提高召回却增加误报，Exact 没有更好。

该方案目前定位为**弱召回与误报的可控权衡组件**，不是已证明稳定提升 Exact 的独立创新。当前已验收分段候选继承了固定 6.25% 配对头，但没有完成“移除全部历史配对训练”的完整结构消融，不能把后续分段头收益倒推为配对收益。

证据：[大校准池与定向配对复核](calibration_targeted_cpu_20261104/review.html)。

## 7. 新增方法三：SawFM/MFT 多尺度分段统计残差读出

### 7.1 相对原方案新增了什么

原全局均值/标准差把全部时间位置合并，不能直接保留“局部统计在什么时间段出现”的粗粒度信息。新增方法从同一冻结主干读取 1/2/4 段统计，经训练集 PCA 统一到 128 维后，用相同 `128→32→2` 小头增加 SawFM/MFT 残差。

关键控制不是只比较“旧模型与加头模型”，而是同时比较：

- `global128`：当前投影后的全局特征；
- `global256`：投影前的全局均值/标准差；
- `segments124`：保留粗粒度时间结构的分段统计。

三组小头均为 **4194 个可训练参数**，训练预算、BCE、配对比例、自然与配对抽样序列以及主验收阈值均相同。因此可以较好地区分“更多训练/更多头参数”与“不同读取位置”的收益。各组 PCA 固定系数数量不同，完整存储和变换成本并不完全匹配。

### 7.2 五种子独立报告结果

| 方法 | Exact | SawFM 弱召回 | MFT 弱召回 | 两目标平均弱 AP | 两目标平均 FPR |
| --- | ---: | ---: | ---: | ---: | ---: |
| 固定配对候选 | 74.683% | 51.582% | 70.138% | 77.911% | 4.322% |
| 同预算 global128 | 74.816% | 51.785% | 70.117% | 78.059% | 4.209% |
| global256 | 74.965% | 52.009% | 69.904% | 78.485% | 4.095% |
| **segments124** | **75.724%** | **52.615%** | **76.791%** | **80.903%** | **3.742%** |

| 对比 | Exact 增益 | 条件配对 95% 区间 | 正向种子 | 验收 |
| --- | ---: | --- | ---: | --- |
| segments124 − 固定参考 | **+1.042 pp** | `[+0.739,+1.345] pp` | 5/5 | 通过 |
| segments124 − global128 | **+0.908 pp** | `[+0.665,+1.151] pp` | 5/5 | 通过 |
| global256 − global128 | +0.149 pp | `[-0.030,+0.328] pp` | 3/5 | 未通过 |

### 7.3 能支持的解释

MFT 弱召回 +6.652 pp，区间 `[+2.733,+10.572] pp`，同时其 FPR 下降 0.938 pp；两目标平均弱 AP +2.992 pp，区间 `[+2.264,+3.720] pp`。因此，收益不只是调低阈值换取更多正预测。

SawFM 弱召回只增加 1.033 pp，区间 `[-0.420,+2.485] pp`，尚未确认稳定改善。该方法对 MFT 的作用明显强于 SawFM。

每种子平均修正 151.2 条原本整组判错的样本，同时引入 67.2 条新整组错误，净增 84 条完全正确样本。其他四类 logits 和阈值不变。

这是当前最值得保留的方法贡献之一：**在不重训主干的条件下，采用轻量、维度受控的多尺度局部统计读出改善特定混合分量的检测。** 仍不能排除它部分利用生成器的时间位置规律。

证据：[完成复核](segment_statistics_cpu_20261105/review.html)、[验收 JSON](segment_statistics_cpu_20261105/candidate_assessment.json)。

## 8. 新增方法四：ISRJ 独立分段头

### 8.1 设计

保留上一轮所有权重与阈值，仅增加一个 `128→32→1`、**4161 个可训练参数**的 ISRJ 残差头。全局 128 维输入与分段 PCA128 输入采用相同头结构和训练预算；本轮只使用自然 32k 采样，不增加新的配对训练，避免把 ISRJ 特征收益与采样改变混在一起。

### 8.2 五种子独立报告结果

| 方法 | Exact | Macro-F1 | ISRJ 弱召回 | ISRJ 弱 AP | ISRJ FPR |
| --- | ---: | ---: | ---: | ---: | ---: |
| 固定上一轮候选 | 75.045% | 95.004% | 60.675% | 74.259% | 6.512% |
| 同预算 global128 头 | 75.069% | 95.012% | 60.900% | 74.536% | 6.532% |
| **ISRJ 分段头** | **76.721%** | **95.385%** | **69.202%** | **82.568%** | **5.071%** |

- 相对固定参考：Exact **+1.677 pp**，区间 `[+1.378,+1.975] pp`，五种子均提高。
- 相对同预算 global128：Exact **+1.652 pp**，区间 `[+1.402,+1.902] pp`，五种子均提高。
- ISRJ 弱召回 **+8.528 pp**，区间 `[+4.692,+12.363] pp`。
- ISRJ 弱 AP **+8.309 pp**，区间 `[+6.630,+9.988] pp`。
- ISRJ FPR **−1.442 pp**，区间 `[-2.074,-0.809] pp`。

每种子平均修正 215 条原整组错误，同时引入 79.8 条新错误，净增 135.2 条完全正确样本。其他五类输出和阈值逐元素不变。

这是当前证据最完整的新增标签头：排序、召回、误报和整体 Exact 同时改善，且胜过全局输入控制。它支持“ISRJ 对局部时间统计具有较强需求”的解释，但不等于证明学习到了切片转发的完整物理机制。

证据：[完成复核](isrj_segment_cpu_20261105/review.html)、[验收 JSON](isrj_segment_cpu_20261105/candidate_assessment.json)。

## 9. 最新一轮：SawFM 可训练投影与容量控制

### 9.1 验证的问题

在保持已验收模型其他五类输出不变的条件下，检查 SawFM 的瓶颈是否主要来自固定 PCA 丢弃了判别方向。比较三组：

| 方法 | 结构 | 可训练参数 | 实际完成种子数 |
| --- | --- | ---: | ---: |
| pca_small | 冻结 PCA128→32→1 | 4161 | 5 |
| pca_wide | 冻结 PCA128→442→1 | 57461 | 5 |
| learned_projection | 标准化 1792 维统计→32→1，折叠原 PCA 和隐藏层后训练 | 57409 | 2，筛选后停止 |

宽头与投影头仅差 52 个可训练参数，但结构形状和优化几何仍不同。三组均从当前 SawFM 函数初始化，使用 `reference + f_current(x) - f_initial(x)`，保证初始预测一致。冻结的初始头也需存储和参与残差计算，不能忽略其成本。

各模型均自然采样、普通 SawFM BCE、24×250=6000 步，主阈值固定。学习投影只有在两种子 check 中优于冻结参考且不低于两个控制时才扩展五种子。

### 9.2 预筛选与正式报告分别得出什么

两种子 **check 筛选** Exact：固定参考 76.042%、小头 76.042%、宽头 76.463%、可训练投影 76.265%。投影低于参数量相近的宽头，因此没有进入五种子报告，不能给它编造正式测试分数或宣称所有可训练投影无效。

五种子 **独立主报告** 为：

| 方法 | Exact | SawFM 弱召回 | SawFM 弱 AP | SawFM FPR |
| --- | ---: | ---: | ---: | ---: |
| 当前固定模型 | 77.178% | 50.643% | 73.568% | 3.725% |
| pca_small | 77.178% | 50.251% | 73.708% | 3.599% |
| pca_wide | **77.319%** | **50.949%** | **74.064%** | **3.458%** |

宽头相对参考：

| 指标变化 | 均值 | 条件配对 95% 区间 |
| --- | ---: | --- |
| Exact | +0.141 pp | `[+0.002,+0.281] pp` |
| SawFM 弱召回 | +0.305 pp | `[-0.492,+1.103] pp` |
| SawFM 弱 AP | +0.496 pp | `[-0.221,+1.214] pp` |
| SawFM FPR | −0.267 pp | `[-0.649,+0.115] pp` |

Exact 为 4/5 种子正向、1 个持平，区间下界略高于零，但平均增益远低于预设 +0.5 pp 的实用门槛；弱召回、弱 AP 和 FPR 的区间均跨零。每种子平均修正 32.4 条整组错误、引入 21 条，净增 11.4 条。

**本轮结论：可训练投影未通过筛选，扩宽小头未通过正式采用门槛，继续保留当前 ISRJ+SawFM/MFT 分段候选。** 现有证据不支持把简单扩宽或继续训练该头作为已验证的主要增益来源，也不能据此排除其他特征或其他训练配置。

本轮 12 个新增模型、72,000 个实际优化器步全部完成，CPU 并行耗时 10 分 22 秒；124 项测试、360 组指标重放通过。完成后另核验 129 份冻结源文件，重算 45 组主预测/决策指标，其他五类 logits 保持一致。

证据：[最新复核报告](saw_projection_cpu_20261107/review.html)、[候选验收](saw_projection_cpu_20261107/candidate_assessment.json)。

## 11. 当前主要缺陷与性能阻碍

### 11.1 SawFM 弱分量仍是重要瓶颈

最新主报告中，SawFM 弱召回约 50.6%，明显低于 MFT 的约 79.7% 和 ISRJ 的约 70.5%。分段统计、继续训练、容量扩展和当前可训练投影，都没有确认其弱边界获得稳定明显改善。

上一轮 ISRJ 报告上，“只有该标签判错”的样本数均值为 SawFM 505.0、ISRJ 380.6、MFT 238.6、SinFM 197.8、FMB 180.4、AMA 68.6。该统计用于错误归因，属于当时的报告池，不能直接当作最新池的计数，也不是可实现增益的预测。

### 11.2 训练覆盖外的极弱分量没有解决

在 ISRJ 分段轮的 10–40 dB 宽功率池中，20–30 dB 分量差距下 ISRJ 召回仅约 9%，并未随主分布提升而改善。SawFM/MFT 分段轮的同类极端差距诊断，两目标召回也仅约 6.4%。

这首先是训练覆盖外的问题；现有结果不能区分信息不足、主干表征不足和决策阈值不匹配各自的贡献，更不能直接宣称原始信号“不可观测”。

### 11.3 时间位置与物理参数泛化仍有限

最新轮冻结权重后的独立诊断池结果：

| 报告条件 | 当前模型 Exact | 宽头 Exact | 宽头相对当前 |
| --- | ---: | ---: | ---: |
| 主分布 | 77.178% | 77.319% | +0.141 pp |
| 分量 JNR 10–40 dB | 54.668% | 54.747% | +0.079 pp |
| 到达时间 50–90 微秒，训练为 10–50 微秒 | 69.603% | 69.554% | −0.050 pp |
| SawFM 周期 80–120 微秒，训练为 20–80 微秒 | 76.042% | 76.240% | +0.198 pp |

这些池身份互相独立。主分布与到达时间池的绝对差不能全部解释为时间偏移的配对因果效应。到达时间仍采用原仿真器 `np.roll` 约定，不代表真实信道、截断或接收窗变化。既往 0/1/3/7 个采样点的小平移最多只有 0.7 微秒，也不足以排除位置线索依赖。

### 11.4 验证与工程方面的边界

- 数据仍来自同一 Python 物理移植与 PCG64 随机流；不是 MATLAB 波形逐点复现，尚缺实测、跨生成器和真实接收链路验证。
- 五种子区间是**固定身份池条件下的模型种子配对区间**，不包含完整的数据总体不确定性；次要比较没有统一做多重检验校正。
- 各轮正式报告均已消费，后续选型应使用新身份，不能在当前报告上反复挑结构或阈值。
- 多个残差头、两套主干与历史依赖增加维护和推理成本；当前尚未完成统一部署模型、蒸馏或全链路成本核算。
- 固定 calibration 的经验误报预算并不保证新测试池严格等 FPR，不能据此把召回提升写成“同等误报下提升”。

## 12. 如何表述目前的方法贡献与下一步

### 12.1 适合用于阶段汇报的贡献表述

可表述为：

> 面向标签长尾和分量功率不均衡下的多标签复合干扰识别，建立了采样、损失、阈值与表征读取的分离验证流程；在冻结主干和固定决策条件下，通过多尺度分段统计及标签专用残差头，提高 MFT、ISRJ 弱分量的排序和识别能力，并使用同预算全局读出控制、五种子及独立身份池验证新增收益。

支撑这一表述的重点是分段读出相对同预算控制的 +0.908 pp 和 +1.652 pp Exact，以及 ISRJ 在弱召回、弱 AP、FPR 上的同时改善。普通 BCE、PCA、时间分段均值/标准差和小型 MLP 本身都是已有技术；当前项目价值在问题针对性组合、按标签的受控残差读取及较完整的收益归因。要形成论文级创新主张，仍需补齐相关工作差异、跨分布复现与更完整消融。

不宜写成：“提出全新 Query2Label 并把准确率从 49% 提高到 77%”“one-bit 配对稳定提升整体识别”“可训练投影已突破 SawFM”“解决了极弱分量识别”。现有证据均不足以支持这些说法。

### 12.2 依据现有结果拟定的待验证事项

以下是后续实验假设，尚未被本轮结果证明，也未在本次文档整理中启动：

1. **固定当前模型，完成更大范围、同身份配对的物理参数诊断。** 分别改变到达时间、SawFM 周期及相关生成参数，观察变化前后同一身份的预测，区分位置依赖与真实特征泛化；始终保留原固定阈值。
2. **优先检查 SawFM 的新增证据来源。** 在原始 I/Q、时频或局部相位/频率特征与当前分段统计之间，先做冻结探针和 one-bit 边界比较，再决定是否训练新头；不能把同一特征上的参数扩展当成已有提升方案。
3. **补做最终结构的统一消融和部署成本评估。** 在同一全新池对比移除 SawFM/MFT 分段头、移除 ISRJ 分段头、保留完整候选，核算端到端延迟、内存与主干次数。历史配对模块是否仍有必要，需要单独受控验证。

后续若继续采用本轮正式门槛，应在训练前冻结：同池 Exact 至少 +0.5 pp、至少 4/5 种子正向、配对 95% 区间下界为正，同时设置弱召回、逐类 FPR、弱 AP 与尾类 F1 保护。检查池预选和最终报告验收应继续分开记录。
