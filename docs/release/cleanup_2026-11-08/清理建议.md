# 项目文件清理建议

统计日期：2026-11-08。当前工作区约 383.07 MiB；与项目有关的 E 盘数据和历史输出另列。大小按文件逻辑字节数统计，实际释放空间受 NTFS 压缩、硬链接和回收站影响。本次未删除、移动或上传任何文件。

## 建议清理顺序

1. **先清理重复文献压缩包，约 151.95 MiB。** `文献库/pdf.zip` 内 44 篇论文均与 `文献库/pdf/` 解压副本逐文件 SHA-256 一致，保留解压目录及全文笔记即可。
2. **如需腾出几十 GiB，优先复核 E 盘重复数据。** 两个根目录共有 20 对同相对路径、同大小 MAT，单份合计 47.36 GiB。先按完整哈希确认，并统一代码中的数据路径，再去掉其中一套。
3. **其次筛选旧路线 B 权重。** 2701 个 `.pt` 合计约 32.13 GiB。按实验归档后处理，不按扩展名整批删除。
4. 缓存和重复文档合计不足 1 MiB，腾空间收益很小。
