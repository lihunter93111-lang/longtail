# 长尾学习方法综述与试验建议

更新时间：2026-11-02

仓库路径说明（2026-11-05）：本文移至 `docs/research/`；`projects/`、`data/` 路径相对于仓库根目录，同目录研究文档见文末链接。`文献库/` 是外部本地材料，PDF 和抽取全文未随 GitHub 发布。

## 1. 使用说明

本文根据本地文献库中的 GCD、增量类别发现、开放世界持续学习和复合干扰识别综述，以及本项目已有长尾实验结果整理。文献库并不是传统长尾分类论文的专门合集，因此下文把文献中可以迁移到当前六类复合干扰多标签任务的思路归纳为六个试验方向：数据层、损失层、采样层、分类头与决策层、表征与伪标签层、持续学习与开集扩展。

实验时应先把“标签频次长尾”“组合频次长尾”和“功率可见性长尾”分开。当前根数据 63 个非空组合、每组合 400 条，是平衡数据；只有经过清单和身份审计的派生数据才可用于长尾结论。

## 2. 当前基线和评价要求

当前 Route-A 主基线是 F2/DFMS 复数 I/Q 模型，输入为 `[B,2,3000]`，输出六个独立标签 logits。当前 v3 对照中，BCE + ordinary sampling + F1 calibration 的五种子 development-test 结果为 Macro-F1 `0.925639 ± 0.001556`、六标签 exact `0.651835 ± 0.005762`、Macro-AUPR `0.977776`，稀有组合准确率 `0.548077`。

这组结果是开发证据。新试验必须使用独立输出目录和新 manifest，不能继续用当前 development-test 调参。每项至少保留五种子，并同时报告：

- 每类 AUPR、recall、FPR 和 F1；
- Macro-F1、sample exact、macro-combination exact、Hamming；
- rare/common 组合准确率，按真实标签基数分层的 exact；
- ECE 或 Brier；
- 唯一身份数、重复率、训练预算和计算成本。

固定阈值、F1 校准阈值和组合阈值必须分开报告。阈值只能在 calibration 集上拟合，locked-test 不参与选择。

## 3. 六类常用方法

### 3.1 数据重采样和重构长尾

**基本思想**：增加尾类/稀有组合在训练中的出现次数，或重新构造每个标签、每个组合和每个功率区间的计数。常见做法包括随机过采样、欠采样、class-aware sampler、balanced batch、组合均衡和分阶段采样。

**对当前任务的价值**：多标签任务中，单标签频率和组合频率可能相反。只按标签补尾类，可能把常见组合重复很多次；只按组合均衡，又可能让某些标签过度出现。因此应分别构造 `label_lt`、`combo_lt` 和 `power_lt` 三种协议。

**已经有的结果**：现有 balanced-cycle 已做过，但一次训练预算 8000 只使用约 4890 个不同 fit 身份，重复率约 0.38875，不是严格无放回均衡；其整体结果没有超过 BCE ordinary。不能把它作为最终 sampler 结论。

**建议试验**：

1. `ordinary`：保留当前基线；
2. `label-aware`：按六个标签的有效频次做多标签采样权重；
3. `combo-aware`：按 63 个组合的逆频次采样；
4. `power-aware`：在每个标签或组合内部对 JNR/功率分层；
5. `two-stage sampler`：前半程组合均衡，后半程恢复真实分布；
6. `no-replacement anchor`：每个 epoch 记录唯一身份数，比较相同预算下的重复率和效果。

**必须控制**：相同 fit 身份池、相同训练步数、相同 batch 数和五种子。不能只报告抽样后的训练准确率。

### 3.2 损失函数和类别代价

**基本思想**：通过类别权重或难例权重改变优化目标，使尾类错误的代价更高。常见方法包括 weighted BCE、Focal、Asymmetric Loss、class-balanced loss、Distribution-Balanced loss、Logit Adjustment 和 Balanced Softmax。

在本地审计中，Base-DB/ASL 统一主线以及冻结头中的 BCE/Focal/DB 已经试过，结论是可以改变某些标签或决策边界，但没有得到统一安全收益；当前 v3 只直接形成了 BCE 与 Logit Adjustment 的五种子对照。Logit Adjustment 的整体提升没有通过稳定性结论，组合 exact 的差异很小且区间跨 0。

**建议试验矩阵**：

| 方法 | 主要改变 | 建议用途 |
|---|---|---|
| Weighted BCE | 正样本或负样本按标签频率加权 | 先做最简单的尾类代价基线 |
| Focal/Asymmetric Loss | 降低易样本权重，强调难例和正负不对称 | 检验尾类漏检与头类误报是否同时下降 |
| Class-Balanced BCE | 用 effective number 替代原始频次 | 频次差距较大时的稳定权重基线 |
| Logit Adjustment | 按标签先验调整训练 logits | 作为当前已有结果的复核组 |
| Balanced Softmax | 在归一化或多类头中显式补偿先验 | 仅适合能明确转换为互斥或局部多类的子任务 |
| Distribution-Balanced Loss | 同时考虑标签频率与共现关系 | 重点用于 63 组合长尾，而不是只看六个边缘频次 |

**注意**：多标签任务的负标签远多于正标签，不能直接把多类长尾论文的单一 class weight 套用。至少要分别调正类权重、负类权重和每标签阈值，并报告头类 FPR。

### 3.3 分类头重训、解耦训练和决策校准

**基本思想**：先学习较通用的表示，再冻结或弱化 backbone，只重训分类头，使分类边界不再被头类先验主导。相关思路包括 decoupled training、classifier retraining、cRT、tau-normalization、后验 logit bias 和阈值校准。

**适合当前项目的试验**：

- `stage 1`：按 ordinary 或自然长尾训练 backbone；
- `stage 2`：冻结 backbone，只用 balanced fit 或 calibration 重新训练六类头；
- `stage 3`：比较固定 0.5、逐标签 F1 阈值、组合 exact 坐标阈值和 temperature/bias；
- 检查头重训是否改善 rare exact，同时是否提高 FMB 等头类 FPR。

当前结果已经说明阈值校准很重要：BCE ordinary 的 exact 从固定 0.5 的 `0.605704` 提升到 F1 calibration 的 `0.651835`。因此新模型改动必须和决策规则分层报告，否则容易把阈值收益误写成表征收益。

### 3.4 表征学习、对比学习和原型方法

**基本思想**：让尾类样本在特征空间中形成更稳定的类内结构，并通过 supervised contrastive、self-supervised contrastive、prototype、中心损失或度量学习减轻头类占据特征空间的问题。

文献库中的 GCD/IGCD 工作常用对比表征、原型、自蒸馏和密度支持集。PIM 还指出，直接最大化互信息带有偏向均衡划分的边际熵项；参数化、双层优化可减轻这种 class-balance bias。SimGCD 类方法则强调伪标签偏置和熵正则问题。

**建议试验**：

1. BCE 主损失 + supervised contrastive，正样本按同一标签而非同一组合构造；
2. 每个标签一个 prototype，比较标签相似度和组合相似度；
3. 只在尾类和稀有组合上增加 prototype/center 约束；
4. 对同一身份不同功率视图做正对，对不同背景但同一标签做跨组合正对；
5. 加入轻量特征均衡或熵正则，检查是否造成组合过度均匀化。

**关键风险**：多标签样本不能简单当作一个类别；共享一个组合 prototype 会把 63 个组合重新变成 63 类，泛化到未见组合会变差。必须同时报告单标签和组合指标，并设置容量匹配的普通对比学习对照。

### 3.5 难例、伪标签和一致性训练

**基本思想**：从尾类、低功率、边界样本和只差一个标签的组合中挖掘 hard negatives/positives；使用增强一致性、置信度伪标签或 teacher-student 训练扩大尾类有效监督。

**文献启示**：IGCD 使用密度支持集、伪标签、特征回放和自蒸馏；但不可靠伪标签会造成旧类/新类偏置和不平衡伪标签。当前项目的 hard-negative 分支因严格组留出增益不足、配对元数据欠缺而停止，不能直接复制。

**建议试验**：

- one-bit hard negative：同一背景和身份条件下只改变一个标签；
- 低功率 hard negative：保持标签和背景，改变 JNR 观察漏检边界；
- teacher-student：只对高置信尾类正样本使用伪标签；
- consistency：同一样本的增益、相位扰动和配对功率视图保持标签一致；
- 置信度分层：高置信样本用于训练，中置信样本只用于一致性，低置信样本不进入伪标签。

所有 hard negative 必须记录 receiver/background/target/noise 身份。伪标签试验必须报告伪标签覆盖率、精度、尾类覆盖率和错误累积，而不是只报告最终 F1。

### 3.6 GCD、聚类和开放世界持续学习

**基本思想**：把未知或未标注数据映射到特征空间，估计新类数量、聚类并逐步加入增量学习。文献库包含 GCD、IGCD、PAUL、ProtoGCD、MORE 等方向。

**与当前任务的关系**：这不是普通长尾分类的第一步。现有文献已经覆盖“开集检测—未知聚类—增量学习”的一般流水线，因此不能把简单 HDBSCAN/伪标签增量训练直接写成创新。

更值得做的是成分级路线：先预测已知多标签，再提取已知成分条件化 residual，在 residual 上检测和聚类未知成分；同时区分未见已知组合、低可见已知成分和真正未知物理成分。持续学习阶段再增加未知簇稳定性、簇纯度、错误晋升率、重复建类率和旧类遗忘指标。

## 4. 推荐的试验优先级

### 第一优先级：建立可信长尾基线

1. ordinary BCE；
2. label-aware sampler；
3. combo-aware sampler；
4. weighted BCE；
5. Logit Adjustment；
6. 逐标签 F1 calibration。

所有方法用同一 v3 新身份池、五种子和相同预算。先回答“长尾收益来自采样、损失还是阈值”。

### 第二优先级：拆开表征和决策

固定同一 backbone logits，比较阈值、logit bias、temperature、classifier retraining 和组合约束；再对最佳决策规则重新训练模型。这样可以避免把校准收益误判为新网络收益。

### 第三优先级：单标签边界与困难组合

围绕 ISRJ、SawFM、MFT 和 FMB 做 one-bit hard-negative。先做身份审计与可观测性检查，再做 focal/contrastive/局部头。若原始信号中没有足够差异，停止网络堆叠，转向观测协议。

### 第四优先级：跨功率和组合泛化

用九挡配对视图评估同一身份在不同 JNR 下的表现，增加未见组合留出。报告每个功率层、标签和组合的结果，不把配对视图当独立样本。

### 第五优先级：开集与持续学习

在闭集长尾主线稳定后，再做留出成分、留出组合、未知成分残差、聚类和风险晋升。现有六类只能作为代理未知实验，不能单独证明真实未知机理识别。

## 5. 一项试验的最小记录模板

每次试验至少保存：

- 研究假设和唯一实验编号；
- 数据版本、标签顺序、组合计数和身份交集审计；
- fit/early-stop/calibration/check/locked-test 角色；
- 采样器、损失、阈值、随机种子和训练预算；
- checkpoint、配置、代码版本、SHA-256 和终端收据；
- Macro-AUPR、Macro-F1、exact、rare/common、逐类 recall/FPR、ECE、成本；
- 失败、停止、未执行和部分支持分支的原因。
