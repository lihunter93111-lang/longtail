# 长尾复合干扰识别：合作与交接简要说明

整理日期：2026-11-02。本文基于现有实验总结和历史审计，本次未重跑实验；“最佳”限定于已整理的对应实验对照。

## 1. 研究目标

从长度为 3000 的复数 I/Q 信号中判断多个干扰成分是否存在。当前新六类为 `[FMB, AMA, SawFM, SinFM, MFT, ISRJ]`，共有 63 个非空组合。

研究重点是分清三种困难：**标签出现少、组合出现少、弱分量被强分量遮蔽**，在提高尾类和稀有组合识别能力的同时控制头类误报。建议合作第一阶段聚焦闭集长尾识别，开集发现与持续学习作为后续拓展。

## 2. 之前完成了什么

| 工作 | 已有基础与认识 |
|---|---|
| 数据构造 | 基础六类、九挡功率配对数据及长尾 v1/v2/v3；已有身份、随机种子、组合计数和哈希记录。v3 训练 8000 条，标签 IF=3，实际组合 CF≈7.85，保留 63 组合 |
| 模型基线 | F2/DFMS：复数多尺度编码→幅度/相位延迟融合→时序残差→mean/std 池化→六维分类头；约 25.8 万参数 |
| 训练与决策 | 完成 BCE/Logit Adjustment × ordinary/balanced-cycle 五种子比较，以及固定阈值、逐标签 F1 阈值和组合阈值对照 |
| 跨功率与结构 | anti-alias 在一次性九功率测试上有小幅提升；课程训练、可见性辅助等未形成稳定整体收益 |
| 错误诊断 | 完成冻结 logits、合法组合 MAP 和 Shapley 分析；四个指定错误因素的 oracle 解释约 47.8% 的 exact 损失，仍有较大残余 |
| 历史路线 B | 探索参数估计、分离器与 JNR 专家；部分 JNR 参数任务有有界正结果，IQ 分组、FiLM 和若干路由机制未通过容量或因果对照 |
| 文献准备 | 有 44 篇本地 PDF、全文提取文本和创新审计，供学习与查重 |

**当前 v3 主对照观测均值最好**：BCE + ordinary sampling + F1 calibration，五种子 development-test：

| 指标 | 结果 |
|---|---:|
| Macro-F1 | 0.925639 ± 0.001556 |
| 六标签全部正确的 exact | 0.651835 ± 0.005762 |
| Macro-AUPR | 0.977776 |
| 稀有组合准确率 | 0.548077 |

“±”为种子间标准差。结果说明排序能力较高，但完整组合仍存在明显错误；校准解释了一部分训练方法之间的差异，整体最优也不等于稀有组合最优。这是开发证据。历史 anti-alias locked-test exact 为 0.382099 对 0.376455，属于不同数据和集成协议，不能直接排名。

**已有教训**：很多改动只改善单标签或排序指标，不能稳定改善完整决策；部分弱分量可能缺乏足够可辨识信息，继续堆叠网络不能替代观测条件和数据身份的核验。旧路线 A/B 审计按其历史日期理解，不能将其中“运行中”等状态视为今天仍然成立。

## 3. 后续实验流程与改进思路

1. **核对数据**：确认版本、标签顺序、组合计数与身份。旧基础六类含 VFT、不含 AMA，不能混用标签列；九功率共享身份的视图不能算独立样本。
2. **处理输入**：MAT/HDF5 复数转为 `[B,2,3000]`，逐样本 RMS 归一化。参数回归仅在有效 mask 内计算，无效 NaN 不能当零。
3. **复现基线**：F2/DFMS + BCE + ordinary。历史设置为 AdamW，lr/weight decay 均为 1e-4，batch 32，8 epochs；载入历史 backbone、重建分类头并全模型微调。
4. **修正协议**：新建 manifest 和输出目录，拆开 fit、early-stop、calibration、check 和独立测试。历史 v3 共用 calibration 选 epoch 和阈值，且 balanced-cycle 存在重复采样；先建立真正无放回的长尾 Anchor。
5. **单机制改进**：聚焦只差一个标签的困难组合，例如相同背景下有/无 ISRJ；优先分析 ISRJ/SawFM/MFT 漏检与 FMB 误报，再试标签局部头、困难负样本或组合 margin。
6. **公平验证**：保持初始化、训练预算、身份和五种子一致，比较固定阈值与校准决策；报告 Macro-AUPR/F1、exact、组合等权准确率、rare/common、recall/FPR、ECE 和成本，按功率分层。

历史 hard-negative 分支因严格组留出增益不足、配对元数据欠缺而停止。重启须补齐目标、背景和噪声身份，不能只凭标签相似就称为反事实配对。新增机制应有等容量、置乱或局部消融对照。现有 development-test 已消费，新独立测试须在方案冻结后使用。

## 4. 创新点怎么提炼

以下是**待验证的贡献方向**，依据已有研究审计提出；定稿前须更新文献检索和查重。

| 候选贡献 | 需要证明什么 |
|---|---|
| 频次—组合—可见性分离的实验设计 | 控制其他因素后分别量化三种困难，比单一 IF 更清楚地解释失效原因 |
| 面向组合边界的标签局部学习 | 只差一个标签的困难组合上，在公平对照中提升 exact/稀有组合，同时控制头类误报 |
| 决策偏置与表征不足的分层诊断 | 校准、冻结 logits 归因和重新训练收益分别核验；oracle 仅作诊断上界，不当作模型成绩 |

若拓展开集，可研究**已知成分条件化残差上的未知成分发现**：区分未见已知组合、低可见已知分量与真正未知成分，并验证同一种未知成分能否跨背景稳定聚类。持续学习进一步研究未知簇确认、误晋升和回滚。两者目前属于方案，宜在闭集主线之后独立推进。

复数卷积、注意力、聚类或简单串联开集与增量学习本身不足以构成创新；实验可复现是贡献的基础，也不能单独替代方法创新。

## 5. 合作分工与第一阶段交付建议

建议师兄负责研究问题、历史结果解释、实验协议和论文主张；师弟负责环境复现、数据核验、基线运行和新增消融；双方共同复核结果。

第一阶段交付：**数据身份/角色核验表、五种子基线表、一个单机制改进及其消融**。每次保留配置、manifest、checkpoint、阈值、日志、终态收据和失败原因，不覆盖旧结果。
