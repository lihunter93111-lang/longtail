## 1. 任务定义与证据边界

项目目标是从长度为 3000 的复数 I/Q 脉冲中识别六类复合干扰是否存在，并在部分路线中估计活动分量参数。六类标签为：

```text
[FMB, AMA, SawFM, SinFM, MFT, ISRJ]
```

六类多标签任务允许全部非空组合，共 `2^6-1=63` 种组合。由于长尾场景中样本级 exact 会同时受到多个标签错误影响，核心测评同时包含单标签指标和组合级指标。所有实验需要记录数据身份、功率视图关系、随机种子、哈希、checkpoint、阈值和终端收据。

当前证据分为三类：

| 证据角色 | 用途 | 能否作为最终泛化结论 |
|---|---|---|
| audit / manifest | 验证数据构造、标签、身份和哈希 | 不能单独支持模型性能 |
| development / check / diagnostic test | 训练、选 checkpoint、校准和机制诊断 | 只能作为开发证据 |
| locked test | 一次性预注册比较 | 可支持对应协议下的最终比较，但不能再用于调参 |

标识为 `20260905` 的 fresh six-class Stage-A 和 `20260907` 的冻结 logits 归因均标记为 `locked_test_used=false`。历史 anti-alias 一次性测试另有 `locked_test_used=true` 的收据，两者的证据角色须分别表述。

### 2.3 MAT 读取、I/Q 归一化和角色拆分

Stage-A 训练脚本对 HDF5/MAT v7.3 做以下处理：

- 用 `h5py` 读取 `iq_complex`、`label_selected` 和 `receiver_noise_seed`；
- 对 HDF5 fancy indexing 先排序索引，读取后恢复原请求顺序，避免索引错误；
- 将复数 I/Q 变为 `[B, 2, 3000]` 的实部/虚部通道；
- 对每个样本做 RMS 归一化：`x / sqrt(rms^2 + 1e-12)`；
- 保留六列 multi-hot 标签；本轮是分类任务，没有把参数真值作为模型输入，也没有联合参数回归。其他参数估计路线须单独检查 `parameter_mask`，不并入这里的性能主张；
- 固定角色：fit 8000 条，calibration 1008 条，check 1008 条，development-test 4032 条；
- calibration 同时用于按 Macro-AUPR 选 checkpoint 和拟合阈值，这是当前 Stage-A 的协议局限；check 不参与阈值搜索，development-test 用冻结决策评估，之后应按已消费开发证据管理；
- balanced-cycle 训练实际只使用 4890 个不同 fit 身份，整体重复率为 0.38875，因此只能称为重复采样代理，不能称为严格无放回均衡。

## 3. 模型结构与训练设置

### 3.1 F2/DFMS I/Q 主干

主实验使用 `F2_DFMS_Full`，代码注册名为 `dfms_iq`。输入是归一化的 `[B,2,3000]` I/Q，输出为 6 个独立标签 logits。结构包含：

1. 复数 I/Q stem，保留幅度和相位信息；
2. 延迟多尺度融合（Delayed Fusion Multi-Scale）；
3. phase lag `(1, 4, 16)` 分支；
4. 多尺度时序卷积和融合，包含 kernel `3/7/15`、dilation `1/2/4` 的 depthwise residual 分支；
5. 全局统计池化（mean/std）和线性投影；
6. dropout `0.2`、宽度 `16`，参数量约 `257,511`；
7. 六维分类头，使用 `BCEWithLogitsLoss` 或 Logit Adjustment 训练。

按 `width=16` 展开的主要形状如下；复数层的通道数分别对应实部和虚部两条流：

| 模块 | 输出形状/维数 | 核心操作 |
|---|---|---|
| I/Q 输入 | `[B,2,3000]` | 实部、虚部，样本 RMS 归一化 |
| complex block 1 | 每流 `[B,16,3000]` | 两个复数卷积，kernel 7，残差、分流 BN、SiLU |
| downsample + block 2 | 每流 `[B,32,1500]` | AvgPool/2，复数残差 kernel 5 |
| complex stage 3 | 每流 `[B,48,750]` | 多尺度 `k=3/7/15`、`d=1/2/4`，投影和残差 |
| complex stage 4 | 每流 `[B,64,375]` | 同类多尺度块，再下采样 |
| late fusion | `[B,128,375]` | Cartesian + magnitude + 有界 phase residual；相位差在深层复数特征上计算 |
| depthwise temporal residual | `[B,128,375]` | 三分支时序残差 |
| 全局 mean/std | `[B,256]` | 不带注意力的统计池化 |
| projection + classifier | 128维特征 → 6 logits | Linear/LayerNorm/GELU/Dropout，分类头 `Linear(128,6)` |

```mermaid
flowchart LR
    X["I/Q 2×3000"] --> E["复数残差与多尺度编码\n16→32→48→64"]
    E --> F["延迟融合\nCartesian + magnitude + phase"]
    F --> T["128通道时序残差"]
    T --> P["mean/std → 128维"]
    P --> Z["6 logits"]
    Z --> D["sigmoid + 校准阈值"]
```

默认 `dfms_iq` 没有额外注意力、跨层金字塔或局部 top-k 分支；anti-alias 变体在降采样前加固定 `[1,4,6,4,1]/16` 低通滤波，参数量保持 257511。两种变体的成绩分别见后文。

### 3.2 训练条件与对照

Stage-A 进行了 20 个作业：

```text

```

统一设置：

| 项目 | 设置 |
|---|---|
| 优化器 | AdamW |
| 学习率 | `1e-4` |
| weight decay | `1e-4` |
| batch size | 32 |
| epoch | 8 |
| 梯度裁剪 | 5.0 |
| checkpoint 选择 | calibration Macro-AUPR 最大者 |
| 设备 | CUDA |

普通 BCE 使用原始 logits；Logit Adjustment 在计算训练损失前加 `log(p/(1-p))`，`p` 为 fit 标签频率。当前脚本的推理直接用模型 logits，没有额外再加一次训练 bias。balanced-cycle 每轮预算 8000，使用 4890 个不同身份，重复比例是“索引预算中非唯一部分” `1−4890/8000`，不等于统计有效样本量 ESS。

## 4. 评估与决策流程

模型先输出六个标签 logits，再按以下顺序评估：

1. **排序能力**：每类 AUPR、AUROC 和 Macro-AUPR；
2. **固定决策**：逐标签阈值 0.5，计算 Macro-F1、Hamming、sample/combination exact；
3. **校准决策**：只用 calibration 拟合逐标签 F1 阈值或组合 exact 坐标阈值；
4. **概率校准**：拟合 temperature，报告 ECE/Brier，检查是否只改善概率可信度而不改变 0.5 决策；
5. **组合分析**：报告 63 组合覆盖、稀有/常见组合准确率、按真实基数分层的 exact；
6. **机制诊断**：对冻结 logits 做合法组合 MAP、坐标阈值、单标签 oracle、Shapley 和误差交互分析。

组合 exact 是样本的六个标签全部正确才算正确；`macro_combination_accuracy` 则先按组合分组再等权平均，两者不能混写成同一个指标。

v3 development-test 每组合 64 条，因此 sample exact 与按组合等权的 exact 数值一致；v2 test 长尾，二者会明显不同。所有“±”表示五种子样本标准差（`ddof=1`），不是置信区间。稀有组合按 fit 频次排序取最少的 13 种，常见组合取最多的 13 种，具体并列选择以记录的组合 code 为准；v3 development-test 的 rare 子集有 `13×64=832` 条。

校准实现细节：F1 阈值网格 `0.05–0.95`，共 181 点；组合坐标阈值从 F1 阈值开始做两轮逐标签搜索；temperature 网格 `0.5–3.0`、101 点，以 calibration BCE 最小选择。后者正温度不改变 logit 正负号，所以固定 0.5 下 exact/F1 不变。ECE 使用 15 个等宽 bin，逐标签计算后取平均。

## 5. 主要实验结果

### 5.1 v3 主对照内效果最好：BCE + ordinary + F1 calibration

这是 2026-09-05 fresh v3 Stage-A 五种子试验中综合表现最好的决策方案：

| 条件 | Macro-F1 | combination exact | Hamming loss | Macro-AUPR | rare combination accuracy |
|---|---:|---:|---:|---:|---:|
| **BCE + ordinary + F1 calibration** | **0.925639 ± 0.001556** | **0.651835 ± 0.005762** | 0.072644 | 0.977776 | 0.548077 |
| Logit Adjustment + ordinary + F1 calibration | 0.924435 ± 0.001810 | 0.648611 ± 0.005429 | 0.073785 | 0.977495 | 0.563702 |
| BCE + balanced-cycle + F1 calibration | 0.922661 ± 0.001506 | 0.631300 ± 0.003312 | 0.075984 | 0.976234 | 0.571875 |
| BCE + ordinary + fixed 0.5 | 0.913780 ± 0.007535 | 0.605704 ± 0.026513 | 0.084706 | 0.977776 | 0.461298 |

完整 2×2 对照的 exact 均值：

| 训练条件 | 固定 0.5 | F1 calibration | combo calibration |
|---|---:|---:|---:|
| BCE ordinary | 0.605704 | **0.651835** | 0.649554 |
| Logit ordinary | 0.633879 | 0.648611 | **0.649950** |
| BCE balanced-cycle | 0.634325 | 0.631300 | 0.637004 |
| Logit balanced-cycle | 0.618105 | 0.639038 | 0.639435 |

结论是：校准解释了相当一部分固定阈值差异；高 AUPR 并不代表六标签边界全部正确，也不能据此排除表征问题。BCE ordinary 的 exact 经 F1 calibration 提升 **4.613 个百分点**；同一决策下 AMA 尾标签 recall 从 `0.920801` 到 `0.976465`，FMB 头标签 negative-FPR 从 `0.159879` 到 `0.049194`。temperature 单独将 ECE 从 `0.069480` 降到 `0.043496`，但没有改变 0.5 决策。

“整体最好”也不表示每个长尾指标都最好：BCE ordinary F1 校准的 rare exact 为 `0.548077`，低于部分 balanced-cycle 条件；组合校准时普通 Logit 的 exact 均值比 BCE 高 `0.000397`，其记录的五种子配对 bootstrap CI `[-0.002331,0.003323]` 跨 0。当前证据不足以宣称 Logit Adjustment 有稳定整体增益。balanced-cycle 引入重复与不同身份覆盖，也不构成严格无放回采样对照。

### 5.4 冻结 logits：合法组合 MAP 与最新归因

这一支使用的是 **v2 AMA** 数据和 `seed_3050–3054` 的独立角色拆分，与前面的 **v3 AMA Stage-A** 不是同一份数据 manifest；结果只能在各自协议内解释。


先前 BCE exact 审计比较了 checkpoint 选择与七种决策方式。early-stop Macro-AUPR 与约束 exact-first（AUPR 距最优不超过 0.002）在这五个 seed 都选择 epoch 8；这只能说明 8 epoch 预算内没有分岔。

```text

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓
```

## 7. 当前结论与下一步

当前最适合引用的模型效果是：

> `BCE + ordinary sampling + F1 calibration`，五种子 development-test 的 Macro-F1 为 `0.925639 ± 0.001556`，combination exact 为 `0.651835 ± 0.005762`。

当前最适合引用的最新诊断是：

> 冻结 logits 的 `single_label_contrib`，四因素 Shapley 联合 oracle 只解释约 47.8% 的 exact 损失，主要瓶颈是 ISRJ、SawFM、MFT 漏检和 FMB 误报。
