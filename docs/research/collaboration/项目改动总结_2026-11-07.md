# 长尾复合干扰识别：做了哪些改动，效果如何？

更新日期：2026-11-07｜用途：项目交流与阶段汇报

## 一、项目要解决什么问题

输入一段接收 I/Q 信号，判断其中包含哪些干扰，类别为 FMB、AMA、SawFM、SinFM、MFT、ISRJ。主要困难有两个：训练时标签及组合出现次数不均衡；多个分量叠加时，功率较弱的分量容易漏检。

本文用 **Exact（整组正确率）** 衡量整体效果：一条样本的六个标签全部判断正确，才计为正确。同时检查弱分量召回和误报率，避免通过大量增加误报来换取召回。“弱分量”指比同一信号中的最强分量至少低 10 dB。

**目前最有效的新增改动是：冻结已有主干，读取其局部时间特征，再用小型分类模块修正特定标签。** SawFM/MFT 分段模块和 ISRJ 分段模块分别通过了独立身份池的五种子验证；最新固定模型在新测试池上的 Exact 为 **77.18%**。SawFM 弱分量仍是主要瓶颈，最近尝试的可训练投影和扩宽模块未达到采用门槛。

## 二、改动与结论一览

下表每一项增益均来自**该轮同一测试池内的对比**。不同轮次使用不同样本，表内增益不能相加，也不能把各轮绝对分数连成一条提升曲线。

| 解决的问题 | 具体改动 | 直接结果 | 当前结论 |
| --- | --- | --- | --- |
| 长尾收益来源不清楚 | 统一比较采样、损失和逐标签阈值 | BCE 仅做阈值校准就带来 +5.67 个百分点 Exact；损失替换未显示额外稳定优势 | 先分清训练收益与决策收益 |
| 同一训练分布难兼顾所有标签 | FMB 用组合采样专家，其他标签用自然采样模型 | 相对同池自然 BCE+校准，Exact **+5.43 个百分点** | 保留按类分工，代价是两套主干推理 |
| 全局特征上的分类边界不足 | 冻结主干，增加非线性局部分类模块 | 独立复现中相对线性头，Exact **+1.35 个百分点** | 非线性决策模块有效 |
| 弱分量边界样本不足 | 加入 6.25% 按功率差分层的单分量增删配对 | 平均弱召回 +2.20 个百分点，但 Exact 仅 +0.18 个百分点，误报上升 | 有召回权衡价值，整体正确率收益未确证 |
| 全局池化丢失局部时间结构 | 增加 SawFM/MFT 的 1/2/4 段统计读出 | Exact **+1.04 个百分点**；MFT 弱召回 **+6.65 个百分点** | **通过验收，保留** |
| ISRJ 的局部信息读取不足 | 单独增加 ISRJ 分段统计模块 | Exact **+1.68 个百分点**；弱召回 **+8.53 个百分点**，误报下降 | **通过验收，保留** |
| SawFM 是否受 PCA 压缩或容量限制 | 放开投影训练，并设置参数量相近的宽头对照 | 投影未通过筛选；宽头 Exact 仅 +0.14 个百分点 | 本轮不升级模型 |

## 三、从改动到结论：关键实验

### 改动 1：拆开采样、损失和阈值，再让不同标签采用合适的分支

**原问题。** “组合采样得分高”可能来自训练曝光改变，也可能只是更适合固定 0.5 阈值。若同时改损失和阈值，就无法判断收益来源。

**做了什么。** 使用同一 DFMS-IQ、同一新身份池、五种子和相同训练预算，分别比较 ordinary BCE、label-aware sampler、combo-aware sampler、weighted BCE、Logit Adjustment；每个模型再分别使用固定 0.5 和逐标签 F1 校准。

| 方法 | 固定 0.5 的 Exact | F1 校准后的 Exact |
| --- | ---: | ---: |
| ordinary BCE | 57.70% | 63.37% |
| label-aware sampler | 56.78% | 62.17% |
| combo-aware sampler | **65.26%** | 63.80% |
| weighted BCE | 57.28% | 56.63% |
| Logit Adjustment | 63.78% | 63.50% |

**结果说明。** BCE 的主要提升来自阈值校准；组合采样在固定阈值下占优，但双方都校准后优势明显缩小。标签采样仍受标签共现影响，没有真正平衡各类曝光。weighted BCE 与 Logit Adjustment 未显示值得替换普通 BCE 的额外优势。

首轮发现不同种子间存在偏移轮采样流复用，后续已修正随机种子派生，并在新报告池复核采样方案。修正后的按类融合使用“FMB 组合专家 + 其他标签自然 BCE”，Exact 从同池的 **63.00% 提高到 68.42%**，增加 **5.43 个百分点**，五种子均提高。

**结论。** 不同标签对采样分布的需求不同。保留 FMB 专家分工；不把逐类校准收益写成新网络收益，也不把组合采样视为对所有标签都最优。

### 改动 2：冻结主干，用非线性模块修正困难标签的决策边界

**原问题。** 主干特征已经具备一定区分能力，但线性分类器可能不能充分利用这些特征。直接重训整个网络，难以判断是表征还是决策边界发生了改善。

**做了什么。** 固定主干，在全局 128 维特征上增加小型非线性残差模块，只修正 SawFM/MFT/ISRJ 的得分；设置线性头重训与自然采样非线性头对照。

**结果。** 在新训练身份和新报告池的复现中，非线性模块相对自身线性基线，Exact **73.43%→74.78%**，增加 **1.35 个百分点**，五种子均提高，95% 配对区间为 `[+0.91,+1.79]` 个百分点。

另对 SawFM/MFT 加入少量配对训练：每对共享背景和噪声，只增删一个目标分量；按功率差分层，每 batch32 使用 30 条自然样本和 1 对配对样本，配对视图占 6.25%。它相对固定参考使两目标平均弱召回增加 **2.20 个百分点**，但 Exact 只增加 **0.18 个百分点**，区间跨零，误报也增加。相对相同预算的自然继续训练，额外 Exact 收益仅 **0.08 个百分点**。

**结论。** 非线性决策模块的作用得到复现；配对训练的独立贡献主要体现为弱召回与误报的权衡，尚不能认定它稳定提高整体正确率。当前结构继承了该配对模块，但后续分段方法的收益不能归因于配对训练。

### 改动 3：保留粗粒度时间结构，改善 SawFM/MFT 读取

**原问题。** 原模型把整个时间轴合并为全局均值和标准差，局部结构出现在哪个时间段的信息会被压缩。继续加大同一种全局分类头，未必能补回这些信息。

**做了什么。** 从冻结主干的 `128×375` 时序特征中，分别按 **1 段、2 段、4 段**计算各通道均值和标准差，拼成 1792 维向量；用训练集拟合标准化和 PCA，压到 128 维，再输入 `128→32→2` 的 SawFM/MFT 残差模块。

**怎样判断收益来自哪里。** 三组都使用相同的 4194 个可训练参数、相同训练预算、相同抽样序列和原固定阈值，只改变输入特征：原全局 128 维、投影前全局 256 维、分段统计。由此控制额外训练和分类模块容量的影响。

| 方案 | Exact | MFT 弱召回 | SawFM 弱召回 | 两目标平均误报率 |
| --- | ---: | ---: | ---: | ---: |
| 固定原候选 | 74.68% | 70.14% | 51.58% | 4.32% |
| 同预算全局 128 维控制 | 74.82% | 70.12% | 51.78% | 4.21% |
| 投影前全局 256 维 | 74.97% | 69.90% | 52.01% | 4.10% |
| **1/2/4 段统计** | **75.72%** | **76.79%** | **52.62%** | **3.74%** |

**结果。** 分段方案相对固定参考增加 **1.04 个百分点 Exact**；相对同预算全局 128 维控制，仍增加 **0.91 个百分点**，95% 配对区间为 `[+0.66,+1.15]` 个百分点，五种子均提高。MFT 弱召回增加 **6.65 个百分点**，两目标平均弱 AP 增加 **2.99 个百分点**，误报同时下降。

**结论。** 主要收益来自对已有局部时间信息的读取，且集中在 MFT；不能简单解释为加参数、延长训练或降低阈值。SawFM 弱召回的提升区间仍跨零，尚未确认稳定突破。**采用该分段模块。**

### 改动 4：把分段读取扩展到 ISRJ，并隔离其贡献

**原问题。** 上一改动对 MFT 有效，但 ISRJ 仍有较多漏检和误报，需要验证它是否也受益于局部时间统计。

**做了什么。** 固定上一轮完整模型，只增加一个 `128→32→1`、4161 个可训练参数的 ISRJ 残差模块。与相同容量的全局特征模块比较；只用自然样本训练，不增加新的配对样本；其他五类输出和全部阈值固定。

| 方案 | Exact | ISRJ 弱召回 | ISRJ 弱 AP | ISRJ 误报率 |
| --- | ---: | ---: | ---: | ---: |
| 固定上一轮候选 | 75.04% | 60.67% | 74.26% | 6.51% |
| 同预算全局特征模块 | 75.07% | 60.90% | 74.54% | 6.53% |
| **ISRJ 分段模块** | **76.72%** | **69.20%** | **82.57%** | **5.07%** |

**结果。** 相对固定参考，Exact 增加 **1.68 个百分点**；相对同预算全局模块，仍增加 **1.65 个百分点**，95% 配对区间为 `[+1.40,+1.90]` 个百分点，五种子均提高。ISRJ 弱召回增加 **8.53 个百分点**、弱 AP 增加 **8.31 个百分点**，误报率下降 **1.44 个百分点**。

**结论。** 这是目前证据最完整的新增模块：整体正确率、弱分量排序、召回和误报同时改善，且胜过同预算控制。**采用 ISRJ 分段模块。** 结果支持局部信息有用，但尚不能证明模型学习到了完整物理机制或排除了生成器位置线索。

### 改动 5：尝试解决 SawFM 剩余瓶颈，结果未达到升级条件

**原问题。** 分段统计已经改善 MFT 和 ISRJ，但 SawFM 弱召回仍偏低。可能原因之一是固定 PCA 丢弃了判别方向，也可能只是分类模块容量不足。

**做了什么。** 固定其他五类输出，比较原尺寸小头、参数量相近的宽头与可训练分段投影；保持起始预测、自然抽样、训练预算和阈值一致。

**结果分两步看。** 可训练投影在两种子筛选中未超过宽头，按预定规则停止，没有进入五种子正式报告。完成五种子报告的控制组如下：

| 方案 | Exact | SawFM 弱召回 | SawFM 误报率 |
| --- | ---: | ---: | ---: |
| 当前固定模型 | 77.18% | 50.64% | 3.72% |
| 原尺寸小头继续训练 | 77.18% | 50.25% | 3.60% |
| 扩宽小头 | 77.32% | 50.95% | 3.46% |

宽头 Exact 仅增加 **0.14 个百分点**，95% 配对区间约为 `[+0.002,+0.281]` 个百分点，低于预设 **+0.5 个百分点**的采用门槛。弱召回、弱 AP 和误报改善的区间均跨零。

**结论。** 这一轮没有产生应替换当前模型的新方案。当前配置下，简单扩宽或放开投影没有带来足够大的收益；不能据此否定所有可训练投影或所有 SawFM 特征方案。

## 四、当前最终保留什么，方法贡献是什么

### 当前保留的结构

```text
接收 I/Q
  ├─ 自然训练的 DFMS-IQ 主分支
  │    ├─ 全局特征 → 基础分类与已有局部修正
  │    └─ 时序特征 → 1/2/4 段统计 → PCA128
  │                                  ├─ SawFM/MFT 残差
  │                                  └─ ISRJ 残差
  └─ 组合采样专家 → FMB 输出
       ↓
     合并六类得分 → 原冻结阈值 → 标签集合
```

这里的残差是对指定标签得分的小幅修正。SawFM/MFT 配对头替换了原局部头的对应残差，随后再加分段残差；ISRJ 保留原局部残差，再加独立分段残差。所有历史头并非无差别叠加。

### 最值得交流的方法贡献

**方法贡献：对已有时序特征进行多尺度分段统计，再按标签训练轻量残差模块。** 与直接扩大分类器相比，它明确改变了信息读取方式；与重训整个主干相比，它能隔离局部信息读取的作用。

**验证贡献：把收益来源拆开比较。** 同时设置冻结原模型、同预算全局模块和分段模块，固定主阈值、保护其他标签，用五种子及独立身份报告池检验，减少把额外训练、阈值变化和容量变化误认为新表征收益的风险。

分段均值/标准差、PCA、MLP 本身都是已有技术。这里总结的是相对本项目原方案的新增设计与实验证据；论文层面的新颖性仍需结合相关工作另行论证。

### 最新固定模型的表现

| 指标 | 最新独立测试池结果 |
| --- | ---: |
| Exact | **77.18%** |
| Macro-F1 | **95.57%** |
| Macro-AUPR | **99.13%** |
| SawFM / MFT / ISRJ 弱召回 | **50.64% / 79.68% / 70.46%** |

该测试池有 8064 条新身份样本，63 种组合等量取样；数值是五种子分别测评后的均值，**不是五模型集成**。77.18% 与上一轮 76.72% 来自不同测试池，二者之差不代表本轮提升，也不能用早期另一套 joint 数据的约 49%–51% 与它直接比较。

## 五、还有什么问题没有解决

| 问题 | 目前证据 | 对后续工作的含义 |
| --- | --- | --- |
| SawFM 弱分量仍难识别 | 最新弱召回约 50.64%，分段、宽头和当前投影没有确认稳定大幅改善 | 下一步应检查新的有效证据来源，而不能默认继续加宽有效 |
| 超出训练范围的极弱分量 | 既往宽功率诊断中，20–30 dB 分量差下，SawFM/MFT 召回约 6.4%，ISRJ 约 9% | 主分布收益不能外推为极弱分量问题已解决 |
| 时间与物理参数泛化 | 最新到达时间变化池上，当前模型 Exact 约 69.60%，低于主池；两池身份不同 | 需要同身份、单因素改变的配对诊断，确认位置依赖程度 |
| 模拟到实测 | 目前仍是同一 Python 物理仿真器 | 尚缺跨生成器和实测验证 |
| 推理与维护成本 | 当前包含自然主分支、FMB 专家及多个小头 | 尚需统一评估端到端延迟、内存和模块精简价值 |

后续优先考虑三个待验证事项：先用固定模型做同身份物理参数变化诊断；再针对 SawFM 比较新的局部相位、频率或时频证据与现有特征；最后在同一新池完成最终结构消融与部署成本核算。这些是依据现有结果形成的实验假设，尚未证明有效。

## 六、结果可信度与复核入口

最近两轮采用的主要门槛是：同池 Exact 至少增加 0.5 个百分点、至少 4/5 种子正向、种子配对 95% 区间下界为正，同时满足弱召回、误报、弱 AP 和尾类 F1 保护。SawFM/MFT 与 ISRJ 分段模块均通过相对冻结参考和同预算全局控制的比较；最新宽头未通过。

标准化/PCA 只在训练身份上拟合；模型与决策选定并冻结后才测评报告池。相关测试、数据/权重哈希和非目标标签不变检查均有记录。区间反映固定测试池下的模型种子差异，尚未覆盖完整数据总体不确定性；部分次要比较未作多重检验校正。主数据为 v3 的 Python 物理移植，不声称与 MATLAB 随机波形逐点相同。
