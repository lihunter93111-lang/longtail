## 协作顺序

1. 两人先拉取同一main提交，确认标签顺序、数据角色、身份清单和正常推理入口。
2. 师兄交付自然、标签边际匹配、组合加权三个补充专家。各策略配对初始化，融合主模型采用独立初始化并在比较中共享。
3. 师弟交付相同条件下的融合、全局与分段对照，以及逐样本纠正和新增错误清单。
4. 五天汇总实际完成范围。后续围绕IF约1/3与CF约7.85/16矩阵推进，正式比较采用两划分五种子。
5. 每轮新实验在experiment-log下建立带日期目录，记录运行提交、配置、数据哈希、状态与结果。两人分别使用codex/data-主题和codex/readout-主题等独立分支，通过PR汇总，合并后再同步。

## 交接字段

交接包记录experiment_id、split、seed、标签顺序、代码commit、数据角色、身份manifest和SHA256、模型及阈值SHA256、训练更新数、累计样本呈现及恢复状态。预测按sample_id对齐，保存combo_id、六标签真值、六维logit和决策。物理配对另带source_id与干预类型。

骨干fit、融合fit和阈值校准的身份数量分别统计。确认候选在评价前冻结，11月10日已消费的确认身份在后续只作历史分析。新候选使用新登记确认身份。
