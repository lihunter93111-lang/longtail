## 联合验证需要回答的问题

1. 收益是否集中在训练低频组合，控制功率差与分量数后是否保留。
2. 固定阈值下的增益有多少来自分数位置、尺度和排序变化。
3. 同身份到达时间变化下，分段模块的增益是否稳定。
4. 与本机 W 弱视图覆盖联合时，改善样本是否重合。

优先接收模型入口、标准化/PCA 拟合与保存方式、标签融合顺序、冻结阈值、数据生成配置、五种子逐项结果和源文件哈希。共同实验方案见 [阶段复盘](../2026-11-07_阶段复盘与协作计划.md)。
