## 值得接续的工作

- SawFM/MFT 分段统计主要改善 MFT，相对同预算全局 128 维控制 Exact 增加约 0.91 pp。
- ISRJ 分段模块相对同预算全局控制 Exact 增加约 1.65 pp，弱 AP、弱召回和误报同时改善。
- FMB 组合采样专家需要补同成本双自然模型对照。
- 增删配对训练的独立 Exact 收益较小，联合结构消融应检查其必要性。
- SawFM 宽头未通过原实用收益门槛，可训练投影仅完成两种子筛选。

以上均按原稿转述。全局池化、分段统计、PCA、MLP 的机制贡献需要进一步拆分。

## 联合验证需要回答的问题

1. 收益是否集中在训练低频组合，控制功率差与分量数后是否保留。
2. 固定阈值下的增益有多少来自分数位置、尺度和排序变化。
3. 同身份到达时间变化下，分段模块的增益是否稳定。
4. 与本机 W 弱视图覆盖联合时，改善样本是否重合。
