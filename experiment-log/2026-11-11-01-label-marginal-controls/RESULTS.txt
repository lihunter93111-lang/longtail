标签正负边际与组合加权：2026-11-11 实验结果

结论先读
本轮完成了两套独立数据划分、每套五个种子的同预算控制：自然训练 A、标签正负边际匹配 B、组合加权 C。新增 B 的十次完整训练，复用经逐项核验的 A/C 二十个检查点与十个独立主模型。100 个单专家及融合决策先冻结，再生成两套各 4032 个身份的新确认集。开发和确认分别独立复算 5300 个指标，最大差为 2.23e-16 以下。普通推理、仓库独立推理入口和迁移路径的复放均通过。

标签边际调整是有效的基线，不能把组合加权相对自然训练的全部提升都归为组合背景机制。C 相对 B 仍有正增量，尤其是历史指定尾组合，但单专家整体 Exact 的五种子区间在两划分均跨零。共同主模型下，C 仿射融合相对 B 仿射融合的确认增量为 +0.273 / +0.417 个百分点，比 C 相对 A 的 +0.933 / +1.156 个百分点小得多。这里是成对控制的观察，不是因果贡献比例分解。

一、方法与数据约束
A 使用自然的逐标签 BCE。C 对每个身份的六标签 BCE 使用同一个组合权重；其目标分布为 75% 自然分布加 25% 保持组合基数总量的组合内均衡分布。所有身份每轮仍出现一次，C 是加权，不是有放回采样。
令 p_c 为实际 fit 标签正例比例，p*_c 为 C 加权后的正例比例。B 的正例权重为 p*_c/p_c，负例权重为 (1-p*_c)/(1-p_c)。这样 B 与 C 对每个标签的正例、负例总损失权重均相同；每标签平均权重也为 1。不能只匹配正例数而忽略负例。
本轮匹配的是目标函数边际，不改变实际数据配额。原始 fit 标签正例数仍为 [6729,2243,3973,3897,4069,3986]，标签 IF=3，组合 CF=7.85366。C 的有效加权标签 IF 约 2.237、组合 CF 约 5.258；这不等于生成了一个新的实际配额训练集。
B/C 在标签内的样本权重分配仍不同。因此 C-B 对照有助于检验边际权重以外的增量，但也包含梯度方差和共享表征优化差别，不能单凭一个分数断言纯粹物理背景因果机制。

固定条件：W32/dfms_iq、8000 fit、40 epochs、batch32、每模型10000更新、AdamW学习率1e-4余弦降至1e-6、weight_decay1e-4、梯度裁剪5、相同 M 物理弱视图安排。模型种子2300—2304；共同主模型种子2200—2204。B 与 A/C 的初始化哈希和全部40轮样本顺序哈希一致。选择每次训练 early_stop BCE 最低的检查点，不用确认集选 epoch。
每划分另有1008 early_stop、1008 calibration、4032 fusion_fit。每个融合对照共享同一个独立自然主模型及同一 fusion_fit。均值融合固定1/2；仿射融合按标签学习两路系数及偏置，300轮；阈值仅在 calibration 上按标签 F1 网格拟合。不是在开发或确认集最大化 Exact。
本轮融合采用共同的普通 F1 校准，不复用11月10日的 guarded 回退逻辑，也不加入分段物理读出。不能把本轮分数替代历史 weighted_segment_guarded 的结果。

尾组合与校准
沿用原协议指定的13个尾组合，单专家 C 比 B 的尾组合 Exact 高 +1.5144 / +1.4423 个百分点。B 比 A 则为 -0.3606 / -0.1202 个百分点。这个差异支持后续继续验证组合条件信息，并说明仅报告整体 Exact 会遗漏尾部结构。此处仍是相同 IF3/CF7.85 条件中的结果，尚未验证其他长尾强度。
仿射 C 比 B 的尾组合 Exact 高 +0.8413 / +0.0962 个百分点，增量的分布与单专家不相同。
仿射 C 的 macro AP 为99.4915%/99.5355%，ECE为0.6878%/0.6838%。B 仿射相应为99.4781%/99.5168%、0.6933%/0.7201%。ECE使用逐标签15个等宽概率箱后平均。仿射 BCE 含融合及得分校准效果，不能只解释为骨干表征能力提升。
固定0.5的敏感性结果见 results/confirmation_means.csv；没有因为固定0.5在某些组更高而重新选择阈值规则。

三、纠错代价不能省略
C-B 单专家在 split1 平均纠正168.2个身份、同时新增161.8个错误，净增6.4；split2纠正176.4、新增149.6，净增26.8。仿射 C-B 相应为85.4/74.4与102.4/85.6。净增远小于发生变化的身份数。
诊断保护线：每个标签 FPR 增量不超过0.5个百分点，SawFM/MFT/ISRJ三个目标的弱召回下降不超过1个百分点。它是预先记录的诊断线，没有在本轮实施回退；其他标签也完整报告，但不在这组三目标弱召回保护范围内。
C-B 单专家：两划分平均保护均未通过。split1的 ISRJ FPR +0.696pp、SawFM弱召回-1.488pp、MFT弱召回-2.232pp；split2的 SawFM FPR +0.544pp。
C-B 仿射：两划分平均保护都通过，但逐种子通过率均为0/5，不能称为种子级稳健保护。并且未纳入三目标保护的 SinFM 弱召回下降1.213/2.427个百分点，同时其FPR下降0.373/0.958个百分点，体现误报与漏检交换。
相对自然仿射，组合仿射的 split1 MFT 弱召回下降2.634pp，平均保护失败；split2平均保护通过，但逐种子仍为0/5。
弱目标定义是多成分身份中该目标名义功率相对最大成分不高于-10dB。它是物理条件分层，不等于通过存在/移除实验确认了模型依赖目标本身。

四、开发诊断与下一步解释
开发 C-B 单专家的整体增量为+0.3919/-0.0942pp，确认变为+0.1587/+0.6647pp，显示数据身份和种子波动仍会影响结论。
开发诊断先用 fit 组合频次排序，按编码解决并列，每组21个组合；低/中/高频 C-B 分别为 split1 +0.0149/+1.3393/-0.1786pp，split2 +0.1786/+0.5804/-1.0417pp。这些21组合分组与历史13尾组合不是同一个定义，不能直接混用。
AMA出现时 C-B 开发 Exact 为+1.1426/+0.3906pp；AMA不出现时为-0.3831/-0.5948pp。这是值得做受控背景复验的关联，不能据此认定 AMA 是因果来源。没有据这些分组选择新模型或重新拟合确认阈值。
权重 Kish ESS：C约7516.21；B每标签约7629.04—7999.80。它描述权重集中程度；真实每轮覆盖仍为8000、每身份一次，并非丢掉了这些样本。

六、样本、训练及推理成本
每模型40轮×8000=320000次基础身份呈现；十个新B模型共320万次。M功率视图替换保留相同基础身份，不能重复算作新训练身份。A/C各十模型及十个主模型是历史复用，本轮没有重训。
每划分参数拟合身份并集为8000 fit加4032 fusion_fit，即12032，而不是每骨干各8000相加。另1008早停、1008校准用于选择与阈值拟合。当前开发4032、当前确认4032；两划分本轮角色合计44224个独立基础身份。新候选池30240尚未进入本轮任何训练；两套dev候选各6048，仅各取4032，剩余未用部分仍应保留其角色记录。
本轮新生成的数据量：未来fit候选30240 + 两套dev各6048 + 两套确认各4032 = 50400个基础身份。只有其中8064个新dev身份和8064个新确认身份用于当前评价。不能写成新生成50400个都用于训练。
单骨干1,013,191参数；双骨干2,026,382参数，仿射另有18个保存的系数/偏置。GPU RTX5080、torch2.11.0+cu128、TF32关闭，batch32的单骨干约0.302ms/样本，双骨干约0.603—0.605ms/样本；不含数据读取和CPU到GPU拷贝。batch1受到Windows主机调度抖动影响，原始重复计时保留，不据它比较同结构不同权重的速度优劣。
相对主W32，组合仿射 Exact +2.3115/+3.2589pp，但使用两骨干及额外融合监督，不能宣称同计算或同总监督预算优势。相对普通双骨干仿射的+0.9325/+1.1558pp才是更严格的当前方法增量。

七、可支持与不可支持的表述
可支持：在当前复合多标签、IF3/CF7.85及M视图条件下，标签正负边际匹配提供有竞争力的对照；组合加权配合共同仿射融合仍有小幅额外增益迹象，且与尾组合和标签条件有关。宽骨干、专家分配和物理局部读出可以继续组织为同一研究路线，但必须分别量化增量及代价。
暂不可支持：组合加权增益完全来自组合背景；对所有长尾强度、所有标签和所有模型种子稳健；没有误报/漏检代价；同总计算/监督预算更优；今晚已经验证分段物理读出的新增贡献。历史分段实验需沿用原池和原对照单独引用。
没有新开开集或持续学习分支。功率长尾作为后续单独维度，不替代本轮标签/组合双长尾主线。
