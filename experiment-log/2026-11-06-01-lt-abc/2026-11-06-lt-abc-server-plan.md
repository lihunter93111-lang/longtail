# 六标签雷达复合干扰识别｜标签长尾与组合长尾第一轮服务器实验方案

版本 LT-ABC-v1，2026-11-06。适用代码 lihunter93111-lang/longtail，参考提交 63b06e5。本文与同目录 2026-11-06-lt-abc-quotas.json 一起交给服务器执行人员。配置中的 code_order、三组配额、目标组、权重和种子是固定输入。本文给出实验协议与实现任务，训练驱动需要服务器端接入。当前已完成整数配额验算，GPU 结果待实测。

## 1. 研究问题和第一轮预算

以一条长度 3000 的复数 I/Q 信号预测六个成分的存在性。主问题是固定标签频次、样本数、成分数分布和功率条件，提高指定稀有组合的独立训练实例数能否提升其完整识别率。并行问题是采用同一批训练波形，只重新分配各标签正负例的损失权重能否提升 AMA 的排序能力。

|组|训练数据|损失|主要比较|
|---|---|---|---|
|A 基线|按历史 v3 的 63 个配额抽取新训练清单|标准 BCE|共同参照|
|B 组合覆盖|和 A 尽可能共享身份，用 156 个新身份替换 156 个旧身份|标准 BCE|B−A，目标 13 个组合的等权完全正确率|
|C 标签加权|逐条复用 A 的训练身份、波形和各轮顺序|固定的逐标签正负加权 BCE|C−A，AMA 的平均精确率 AP|

首轮 3 组 × 3 个配对模型种子，共 9 次完整训练。功率作为控制条件。暂缓训练 B+C、Head-DB、开集分支和参数估计。此次的 B 检验固定预算下**增加指定组合独立实例、同时减少其他组合实例**的净效应。要单独推断“新增身份比重复旧身份好”，还需另设相同配额的重复采样组，首轮结果仅支持本表中的比较。

历史背景：AMA v3 五种子开发集上，普通 BCE 经逐标签校准后的整体 exact 为 0.651835，rare exact 为 0.548077。balanced-cycle 分别为 0.631300、0.571875，每轮 8000 次只覆盖 4890 个身份。旧含 VFT 的六类 Head-DB 试验对目标尾类 AP 的平均增益接近零。本轮将重新生成身份、拆开选模与校准，且冻结了新的并列尾组选择规则。历史数值仅供检查数量级，组间结论用本轮的配对 A 作参照。

## 3. 冻结组合配额并生成配对训练集

六位编码用 code = Σ y[j] × 2^j，FMB 在最低位，ISRJ 在最高位，取 1…63。A 和 C 的训练标签计数依次为 [6729,2243,3973,3897,4069,3986]，组合计数为 41…322。A、B、C 的基数 1…6 各有 [526,1821,2833,1996,698,126] 条。完整配额逐项读取 JSON。

- [ ] A 有 36 种组合并列最低频，每种 41 条。在这 36 种内按“有无 FMB × 成分数量”分层，以最大余数分配 13 个名额，用固定哈希顺序打破层内并列，已将目标 code 固定为 **4、8、12、24、27、30、36、42、46、48、52、55、56**。这 13 种覆盖了有无 FMB、不同基数的背景。另存全部 36 种、其余 23 种并列低频组、15 种被调低配额的组合、13 种常见组。各组对所有模型使用同一定义。
- [ ] B 中上述 13 种各取 53 个不同身份，增加 29.27%。B 的最低/最高组合计数为 30/322。B 可能加大整体最大最小频数比，因此将干预称作“定向补充稀有组合”。按组合从同一可用候选池先抽 max(A,B) 个身份；构造共享核心 min(A,B)，再将剩余身份分给需增加的组。A 与 B 的交集必须恰为 7844，A 独有与 B 独有各 156。三组总共需要 8156 个不同 fit 身份。
- [ ] 固定数据抽样种子 20261106，配额和数据跨模型种子复用。抽取前按组登记供给数，少于 max(A,B) 时输出缺口 code、缺口数和功率分层；按相同契约补生成，记录生成配置与物理参数种子。筛选只用生成元数据和标签。
- [ ] 训练身份至少保存 source_file_hash、raw_row、生成批次、物理场景或波形身份、活动分量参数/种子、噪声种子、code、可追溯的 JNR。相同底层波形的不同功率视图、重加噪版本归为同一身份。对源索引、噪声种子与物理身份分别查交集。功率视图按身份整体划入一个角色。
- [ ] 用原始生成字段核对 10–30 dB 契约。历史六类派生写入的是各活动分量 JNR 的均值，若源池可取逐分量值，需按活动标签对齐保存。固定功率分箱 [10,15)、[15,20)、[20,25)、[25,30] dB。先在各 code 内按相同生成分布分层选样，检查 A/B 整体及各活动标签的 JNR 直方图。对每个标签要求各箱占比绝对差 ≤1 个百分点、平均 JNR 差 ≤0.25 dB，另外单列 156 个换入/换出身份的摘要，防止共享核心掩盖系统性偏差。若仅有样本均值则不能验收分量功率匹配，回查源元数据。若超限，仅按预定功率约束重做抽取并记录，不改配额；持续不可行则停止 B 并报告。
- [ ] 输出 63 行配额/实取表、共现矩阵、每标签正负数、基数分布、JNR 表和两份训练 manifest。逐项验证实际 counts、唯一身份、交集、标签边际和基数。组合共现的变化正是干预的一部分，作为解释变量保存。

## 4. 新的评测角色和冻结顺序

从同契约的新开发池按 code 各取 96 个独立身份，分层打乱种子 20261107。每个 code 依次分给 early-stop 16、calibration 16、development 64。三份共 1008、1008、4032 条；另有 fit 8000 条/组。三组共享完全相同的开发角色和行顺序。4032 条中目标 13 个组合共有 832 条。开发集衡量组合等权场景，另可用 A 的训练组合权重对 63 个分组分数加权，单列为参考分布下估计。

1. 开训前封存协议、配额、角色 manifest 的哈希，验收所有跨角色物理身份交集为 0。A、B 的共享只允许发生在 fit 角色，C 的 fit 与 A 相同。
2. 训练时每 epoch 只访问 early-stop 选择 checkpoint。训练完成用 calibration 拟合阈值并锁定。
3. 三组所有训练、权重、校准阈值就绪后，统一计算 development。开发结果用于筛选。新的独立确认数据在方案和候选冻结后另行产生并一次评价。
4. 重试仅用于恢复明确的运行错误，沿用同一 manifest、代码、配置和种子。版本或数据变化时另立 run_id。记录跳过/失败原因，禁止依据中间开发分数更换种子。

## 5. 模型、损失、校准

共用 dfms_iq，width=16，dropout=0.2，输入转 [B,2,3000]，用每样本 sqrt(mean(real²+imag²)+1e−12) 作除数。按历史 initialize_f2 装载共享权重，排除旧分类头，重新初始化六维输出，全部参数参与训练。每个种子先保存初始状态哈希，三组校验一致。训练 FP32，AdamW，lr=1e−4，weight_decay=1e−4，batch=32，clip_grad_norm=5，8 epoch，每 epoch 无放回打乱 8000 条，共 2000 次更新。固定相同设备/精度、数据加载和优化设置。模型种子 2050、2051、2052。A/C 每轮顺序完全一致。B 可用相同位置排列，按固定排序将换入身份映射到换出位置，记录索引映射。

A/B 将每条样本的 6 项 BCEWithLogits 取算术平均，再作 batch 平均。C 用同一未约简损失乘元素权重。令 p_j=A.fit 中标签 j 的阳性率，定义

    a+ = clip(0.5 + 0.25/p_j,       0.5, 3)
    a- = clip(0.5 + 0.25/(1-p_j),   0.5, 3)
    d  = p_j*a+ + (1-p_j)*a-
    w+ = a+/d, w- = a-/d
    loss_C = mean(BCEWithLogits(z,y,reduction="none") * (y*w+ + (1-y)*w-))

均值覆盖 batch 和六标签。由整个 fit 计算一次权重，写入运行记录并与 JSON 比对。每个标签验证 p*w+ + (1-p)*w- = 1。特别核对 AMA 正例、FMB 负例得到较高权重。整个过程不叠加重采样、logit correction、功率加权或组合损失。

每个 epoch 按 early-stop 的六标签 macro-AP 选 checkpoint，精确并列取较早 epoch。对最佳 checkpoint 在 calibration 上逐标签搜索 0.05…0.95、步长 0.005 的 181 个阈值，最大 F1，并列取最小阈值，预测用 sigmoid(logit) ≥ threshold。记录固定 0.5 与校准后两套决策。另在 calibration 的 AMA 阴性分数上选满足经验 FPR ≤5% 的最低可行决策阈值（候选含高于最高分的阈值，按实际 ≥ 计数处理并列），在 development 同时报该阈值的实际 FPR 和召回。

## 6. 指标、晋级和停止条件

- 完整识别 exact 指一条信号六位预测均正确，允许模型输出全零并按原样计分。组别 exact 先分 true code 计算再等权平均。每组输出样本数、点估计和各 seed 原值。AP 统一采用 sklearn.average_precision_score，文中历史 Macro-AUPR 对应此口径。
- B 的唯一主指标是目标 13 组校准后 exact 的配对差。护栏为整体 exact、常见 13 组 exact、15 种供体组合 exact。另报全部 36 个并列尾部及剩余 23 个的等权 exact，保留 63 行分组表。若只在目标组提高，按“指定组合改善”表述。
- C 的唯一主指标是 AMA AP 的配对差。护栏为整体 exact、校准后的 FMB 阴性误报率。另报 AMA 在 5% 校准误报约束下的开发召回与实际误报、逐标签 AP/召回/FPR、macro-AP、macro-F1。两项比较都输出错一位的比例及按标签统计的漏检/误报，单列 ISRJ、SawFM、MFT。
- 本轮预先采用下列工程筛选线；它们是拟定的取舍，不是历史显著性界限。单位均为绝对百分点。B−A：三种子目标 exact 均值 ≥+1.0，至少 2/3 个种子为正；整体均值 ≥−0.5、常见组 ≥−1.0、供体组 ≥−1.0。C−A：三种子 AMA AP 均值 ≥+0.2，至少 2/3 为正，整体 exact ≥−0.5，FMB FPR 增量 ≤+1.0。每条护栏都看逐种子原值并在报告中列出最大退化。任一必需条件失败，该分支停止扩展。
- 配对统计按同 seed、同一开发身份比较，每个模型独立拟合阈值。报告全部种子差值、差值均值和标准差。补充 10,000 次按 true code 分层的身份配对 bootstrap，固定种子 20261110，在所有模型上同步重采同一批身份，给出跨既定种子均值差的 95% 百分位区间。该区间仅描述开发身份的不确定性，三个种子的波动从逐种子结果单独判断。
- 分别裁决 B、C。只有通过者进入确认。新 fit/开发身份和五个新模型种子见 JSON；独立确认评测用新的 63×64 个身份，保持相同标签语义、目标名单、配额和选择规则，另备独立 early-stop 与 calibration 各 63×16。复训 A 和通过组；两组都通过时共享五个 A。确认时沿用幅度与护栏，要求至少 4/5 配对方向为正，逐项报告区间。确认前不合并 B+C。初筛与确认均注明对固定配额及数据生成契约的依赖。

## 7. 服务器执行人员的工作顺序

1. 设置仓库根与外部绝对路径，核对基准提交、依赖和外部权重哈希，建独立输出目录，例如 outputs/lt_abc_v1/<run_id>/。仓库内历史实验脚本有 Windows 路径和旧输出复用逻辑，先实现一个独立入口，接受 pool、init、protocol、output、stage、arm、seed；历史脚本作为组件参照。
2. 读取同目录配额 JSON。参考 projects/CJ_Imbalance_0716/experiments/build_direct_sixclass_v3_20260905.py 的 pool_meta、code 映射和 HDF5 顺序恢复，按第 3、4 节构建 manifest。注意旧 write 会把多分量 JNR 压成均值，本轮审计要保留逐分量元数据。
3. 参考同目录 run_route_a_ama_direct_sixclass_v3_2x2_20260905.py 的 I/Q 读取、训练设置与模型构造，复用 run_route_a_c1_baseline.py 的 initialize_f2。独立实现新的角色加载和三种条件；旧 main() 会直接跑旧协议。参考 analyze_route_a_ama_direct_sixclass_v3_2x2_20260905.py 的 fit_f1_thresholds、evaluate，额外传入冻结的目标 code 并保存逐标签 AP，避免 evaluate 按本组训练频次重新选尾组。
4. 做一个训练批次和指标自查。相同权重、相同输入时 A/B 损失相等；C 设置全 1 权重时等于 A；真实权重时逐元素结果匹配公式。人工造两条六标签预测，一条对、一条错一位，exact 应为 0.5。确认阈值与角色隔离、无 NaN、输出形状正确、检查点能恢复。清空本次冒烟在独立临时目录产生的训练状态，正式运行从同一预定初始化开始。
5. 通过数据验收后按种子成对运行 A/B/C。每次生成 checkpoint、训练曲线、最佳 epoch、校准阈值、耗时、相同的初始权重摘要与运行收据。只有配置/数据/代码/权重哈希都相同且所有产物完备，才能复用完成的运行。
6. 所有模型和阈值冻结后统一评分，按第 6 节逐项判定。服务器返回下列文件以及启动命令、代码变更和 run_id。首轮到此结束，记录哪些分支获得确认资格。

|quota_audit.csv、power_audit.csv|全部 63 组的 A/B 目标与实取、共享/独有数、六标签边际、基数和功率偏差|
