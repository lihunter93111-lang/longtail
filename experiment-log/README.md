## 两端怎样更新

1. **本地发布方案。** 先用 `git pull --ff-only` 同步，在本目录新建 `YYYY-MM-DD-NN-主题` 子目录。日期取方案发布日期，NN 从 01 起。放入方案、所需配置和 results.md，在表首添加一行，再提交并推送。
2. **服务器登记运行。** 拉取已发布的提交，在对应 results.md 写入方案提交号、实际训练代码提交号和 run_id。完成数据验收、开始训练或遇阻时，更新该页和上表状态，然后提交并推送。
3. **服务器回填结果。** 同一轮后续结果写在原实验目录，以实际更新日期倒序追加记录。附上各组逐种子指标、对照差值、停止或晋级决定。轻量结果表与收据可放在该子目录，数据、权重和完整预测保留在服务器，登记位置及哈希。
4. **本地复盘。** 拉取最新提交，在本轮结果页补充结论。调整已开始运行的配额、损失或晋级标准时，另建带日期的新实验目录并链接上一轮，保留原协议供回查。

过去各阶段的报告可从[历史实验汇总](../docs/research/当前最佳与最新试验结果说明.md)查阅。
